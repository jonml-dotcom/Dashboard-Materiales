# Construir Mejor · V7 definitiva

## Idea central
**4 casas → auditoría → 1 receta comparable → explicar cada cambio → mercado CR → Should Cost → Casas 5 y 6**

La V7 definitiva corrige el problema detectado en la trayectoria mensual: un pico no se interpreta como encarecimiento hasta demostrar que proviene de precios comparables.

## Hallazgos de auditoría
La revisión previa de las 2.392 líneas detectó:
- 4 líneas de **corte de melamina** homologadas como material permanente. Se reclasifican como servicio.
- 2 líneas de **disco de sierra para melamina** homologadas como melamina. Se reclasifican como herramienta/equipo.
- La clave comparable separa **lámina de melamina**, medida/espesor y unidad comercial.
- Cerrajería separa **bisagra, cerradura y cerrojo** en vez de tratarlos como un único precio.
- **Sistema Superblock** permanece visible, pero fuera de la canasta convencional de la receta/tendencia.

## Tendencia comparable
- Cantidades: receta fija.
- Precio: mediana mensual por variante comparable y último precio conocido.
- La trayectoria principal usa únicamente meses con **≥95% de cobertura económica**.
- Se muestra además la **cobertura fresca**: porcentaje de la canasta cuyo precio observado tiene 180 días o menos.
- Cada cambio mensual puede explicarse por material/familia/sistema.

La antigua curva Casa 1 → Casa 2 → Casa 3 no se utiliza como evidencia, porque la asignación histórica de facturas a casas no quedó demostrada con suficiente precisión.

Casa 4 está confirmada como block convencional. Antes del 23/03/2026 se identifican 860 blocks estructurales: 460 de El Lagar y 400 de EPA. Los 182 Zacate Block se excluyen.
