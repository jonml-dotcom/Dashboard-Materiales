# Construir Mejor — raíz V5

Versión reconstruida desde la V5 original, priorizando una experiencia natural, visual y directa.

## Enfoque
- Historia ejecutiva
- Receta visual
- Material × proveedor
- Evolución de precios
- Fletes cuando existen
- Plan de compra Casas 5 y 6
- Explorador maestro

## Regla de receta
- Materiales comunes: total histórico / 4 viviendas.
- Estructura Casa 4: cantidades reales identificadas desde 23/03/2026.
- Superbloque se conserva separado del block convencional.
- El block previo al 23/03 no se asigna artificialmente a una vivienda específica.

Base: 2.392 líneas homologadas.
